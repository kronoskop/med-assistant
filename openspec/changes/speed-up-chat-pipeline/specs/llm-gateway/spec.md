## ADDED Requirements

### Requirement: Потолок длины генерации
Система SHALL ограничивать длину генерации каждого запроса к модели настраиваемым потолком, отдельным для ответа и для уточнений.

#### Scenario: Потолки по умолчанию
- **WHEN** `ANSWER_MAX_TOKENS` и `CLARIFY_MAX_TOKENS` не заданы
- **THEN** запрос ответа содержит `max_tokens` 1200, запрос уточнений — 400

### Requirement: Время по этапам без клинического текста
Система SHALL записывать для каждого запроса чата время отбора фрагментов, полное время и, для потока, время до первого фрагмента текста. Запись MUST NOT содержать текст запроса, ответа или рассуждения модели.

#### Scenario: Запись времени
- **WHEN** выполнен запрос чата
- **THEN** журнал `app.timing` содержит время по этапам
- **THEN** в записи нет слов врача

### Requirement: Отбор фрагментов не останавливает сервер
Отбор фрагментов SHALL выполняться вне потока event loop, чтобы ожидание модели эмбеддингов не задерживало обслуживание других запросов.

#### Scenario: Отбор в отдельном потоке
- **WHEN** выполняется запрос чата
- **THEN** отбор фрагментов идёт не в потоке event loop
