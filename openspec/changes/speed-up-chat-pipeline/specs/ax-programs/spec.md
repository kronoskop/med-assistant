## MODIFIED Requirements

### Requirement: Структура ответа обеспечивается схемой, а не инструкцией
Выход каждой программы разбирается как структурированные поля, поэтому система SHALL требовать структуру от сервера модели схемой ответа, построенной по выходным полям сигнатуры этой программы. Система MUST NOT полагаться на то, что модель вернёт структурированный ответ в результате одной лишь текстовой инструкции в промпте. Система MUST NOT отправлять в промпте правило формы, противоречащее схеме.

#### Scenario: Схема уходит вместе с запросом
- **WHEN** система отправляет запрос генерации ответа чата
- **THEN** запрос содержит схему ответа, соответствующую выходным полям сигнатуры программы ответа

#### Scenario: Правило формы не противоречит схеме
- **WHEN** система отправляет запрос генерации
- **THEN** системный промпт не требует формы «поле: значение по строкам»

#### Scenario: Модель отвечает свободным текстом
- **WHEN** модель склонна отвечать рассуждением вместо структурированного ответа
- **AND** выполняется запрос чата
- **THEN** ответ, полученный клиентом, содержит текст ассистента, а не рассуждение модели

#### Scenario: Ответ не удалось разобрать
- **WHEN** сервер модели вернул ответ, который не разбирается по выходным полям сигнатуры
- **THEN** система возвращает ошибку с машиночитаемым кодом
- **THEN** система не выдаёт неразобранный ответ как текст ассистента

## ADDED Requirements

### Requirement: Ответ и уточнения — отдельные программы
Система SHALL получать текст ответа и уточнения с противоречиями разными программами и разными запросами к модели. Выход программы ответа SHALL содержать только текст ответа; ссылки на фрагменты SHALL извлекаться из маркеров в этом тексте.

#### Scenario: Два запроса
- **WHEN** клиент отправляет запрос чата и найдены фрагменты основы
- **THEN** к модели уходят запрос ответа и запрос уточнений, каждый со своей схемой

#### Scenario: Ссылки из текста
- **WHEN** текст ответа содержит маркеры фрагментов
- **THEN** заявленные ссылки — эти маркеры в порядке первого упоминания
