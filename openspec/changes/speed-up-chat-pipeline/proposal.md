## Why

Демо пойдёт на Mac врача с MedGemma 4B в LM Studio, и ответ сейчас медленный по устройству конвейера, а не только из-за модели. Модель пишет один JSON из четырёх полей: ответ, список ссылок, уточняющие вопросы и противоречия. Сноски и уточнения ждут, пока она допишет всё. Список ссылок повторяет маркеры, которые уже стоят в тексте. Отбор фрагментов выполняется синхронно в обработчике и останавливает сервер на время эмбеддинга. Ax добавляет в промпт правило «поле: значение по строкам», которое противоречит просьбе вернуть JSON. Потолка длины генерации нет.

Измерить это до сих пор было нечем: нет ни проверочного набора, ни замера времени по этапам.

## What Changes

- Проверочный набор вопросов на русском, узбекском и английском и скрипт замера: время до первого слова, полное время, попадание в нужный документ, отказ на посторонний вопрос.
- Время по этапам в журнале сервера, без клинического текста.
- Ответ и уточнения — две программы и два запроса к модели. Ответ идёт потоком сразу; уточнения считаются параллельно, после ответа или не считаются вовсе, по настройке.
- Ссылки на фрагменты берутся из маркеров в тексте, поле `sources` в выходе модели убрано.
- У каждой программы свой потолок длины генерации.
- Противоречивое правило формы снимается с промпта на границе исходящего запроса.
- Отбор фрагментов не блокирует event loop, соединение с моделью эмбеддингов переиспользуется.
- Поток разбирается инкрементально, а не перечитыванием всего буфера на каждом токене.
- Инструкция просит отвечать на языке вопроса врача: русском, узбекском или английском.

Смена модели, гибридный поиск и реранкер в это изменение не входят.

## Capabilities

### Modified Capabilities

- `ax-programs`: ответ и уточнения — отдельные программы со своими схемами.
- `llm-gateway`: потолок длины генерации и время по этапам.
- `targeted-questions`: уточнения считаются отдельно и не могут уронить ответ.

## Impact

- Код: `app/llm.py`, `app/routers.py`, `app/prompt.py`, `app/settings.py`, `app/corpus/embed.py`, `app/main.py`.
- Новое: `eval/questions.jsonl`, `tools/bench.py`, цели `make bench` и `make bench-retrieval`.
- API и SSE-контракт не меняются.
- При `CLARIFY_MODE=parallel` модель получает два запроса одновременно; если LM Studio ставит их в очередь, нужен режим `after`.
