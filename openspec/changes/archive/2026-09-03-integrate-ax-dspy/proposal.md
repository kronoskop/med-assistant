## Why

Сейчас чат ходит в MedGemma через сырой OpenAI-совместимый `chat.completions`: системный промпт — строка, разбор ответа — ответственность приложения. Нужен DSPy-слой (библиотека Ax, пакет `axllm`), чтобы задача ассистента стала типизированной программой (сигнатура → генерация → валидация), а не кучей промпт-строк. Внешний HTTP API менять не нужно.

## What Changes

- В зависимости добавляется Python-пакет `axllm` (Ax / DSPy для Python). TypeScript-пакет `@ax-llm/ax` не используется.
- Вызов модели идёт через Ax: провайдер `OpenAICompatibleClient` / `ai()` на локальный LM Studio, программа — `ax()` с сигнатурой медицинского ассистента.
- Прямые вызовы `openai.AsyncOpenAI.chat.completions` из прикладного кода убираются. Клиент `openai` остаётся только если его тянет `axllm`, не как API приложения.
- HTTP-контракт чата, health/ready, коды ошибок апстрима и оговорка `disclaimer` сохраняются.
- Оптимизация GEPA, агенты, MCP, tools и облачные провайдеры Ax в это изменение не входят.

## Capabilities

### New Capabilities

- `ax-programs`: типизированные программы Ax для чата ассистента — сигнатура, локальный провайдер, синхронный `forward` и потоковый `streamingForward`, без облачных LLM.

### Modified Capabilities

- `llm-gateway`: генерация идёт через Ax на тот же локальный OpenAI-совместимый URL LM Studio; приложение больше не вызывает chat completions напрямую.
- `chat`: ограничения роли ассистента (поддержка врача, не диагноз, без специализации отделения) задаются сигнатурой/инструкцией Ax; история из запроса мапится во вход программы, а не обязательно как «первое system-сообщение» сырого OpenAI-запроса.

## Impact

- Код: `app/llm.py`, `app/prompt.py`, тесты `tests/test_llm.py` / связанные моки; `pyproject.toml` / lockfile.
- API: без breaking changes для `POST /api/v1/chat`, `GET /health`, `GET /ready`.
- Зависимости: `axllm`; прямой импорт `openai` в приложении снимается.
- Внешняя система: по-прежнему только LM Studio с MedGemma. Облачные ключи Ax/OpenAI не появляются.
- Тесты по-прежнему без живой модели: апстрим подменяется.
