# llm-gateway Specification

## Purpose

Описывает вызов локальной MedGemma в LM Studio: только локальный endpoint, настраиваемый идентификатор модели, таймауты и ошибки, если сервер или модель недоступны.

## Requirements

### Requirement: Только локальный LM Studio
Система SHALL отправлять запросы генерации только на настроенный OpenAI-совместимый базовый URL LM Studio. Система MUST NOT вызывать публичные облачные LLM API (OpenAI, Google, Anthropic и аналоги) для чата.

#### Scenario: Запрос уходит локально
- **WHEN** принят корректный запрос чата
- **THEN** запрос генерации отправляется на настроенный базовый URL LM Studio
- **THEN** генерация чата не отправляется публичному облачному провайдеру LLM

### Requirement: Настраиваемый идентификатор модели
Система SHALL запрашивать генерацию с настроенным идентификатором модели. Идентификатор по умолчанию SHALL быть `med-gemma-1.5-4b`.

#### Scenario: Модель по умолчанию
- **WHEN** `LMSTUDIO_MODEL` не задан
- **AND** отправляется запрос генерации
- **THEN** поле `model` в апстрим-запросе равно `med-gemma-1.5-4b`

#### Scenario: Свой идентификатор модели
- **WHEN** `LMSTUDIO_MODEL` задан непустым значением
- **AND** отправляется запрос генерации
- **THEN** поле `model` в апстрим-запросе равно этому значению

### Requirement: Недоступность апстрима
Если LM Studio не принимает соединения, система SHALL завершить запрос чата с HTTP 503 и JSON `code` `llm_unavailable`.

#### Scenario: Соединение отклонено
- **WHEN** хост LM Studio отклоняет соединение
- **AND** клиент отправляет `POST /api/v1/chat`
- **THEN** система возвращает HTTP 503
- **THEN** JSON-тело содержит `"code": "llm_unavailable"`

### Requirement: Таймаут апстрима
Если запрос к LM Studio превышает настроенный таймаут, система SHALL завершить запрос чата с HTTP 504 и JSON `code` `llm_timeout`.

#### Scenario: Медленная модель
- **WHEN** LM Studio не завершает запрос чата за настроенный таймаут
- **AND** клиент отправляет нестриминговый `POST /api/v1/chat`
- **THEN** система возвращает HTTP 504
- **THEN** JSON-тело содержит `"code": "llm_timeout"`

### Requirement: Ошибка апстрима
Если LM Studio возвращает HTTP-ошибку (в том числе неизвестный идентификатор модели), система SHALL завершить запрос чата с HTTP 502 и JSON `code` `llm_error`. Текст для клиента MUST NOT содержать сырые секреты апстрима.

#### Scenario: Неизвестная модель
- **WHEN** LM Studio отвечает, что модель не найдена или не загружена
- **AND** клиент отправляет `POST /api/v1/chat`
- **THEN** система возвращает HTTP 502
- **THEN** JSON-тело содержит `"code": "llm_error"`
- **THEN** `message` — короткое пояснение для человека

### Requirement: Настраиваемый таймаут запроса
Система SHALL применять числовой таймаут к вызовам LM Studio. Таймаут по умолчанию SHALL быть 120 секунд. Значение SHALL переопределяться через `LMSTUDIO_TIMEOUT_SECONDS`.

#### Scenario: Таймаут по умолчанию
- **WHEN** `LMSTUDIO_TIMEOUT_SECONDS` не задан
- **THEN** апстрим-вызовы чата используют таймаут 120 секунд
