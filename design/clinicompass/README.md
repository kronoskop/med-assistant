# Макет интерфейса CliniCompass

Исходники канваса Claude Design: шесть экранов ассистента в фирменном стиле продукта.

| Файл | Экран |
|---|---|
| `Main.dc.html` | Ответ с двумя уровнями доказательств |
| `Empty.dc.html` | Пустое состояние, темы корпуса |
| `Streaming.dc.html` | Идёт генерация |
| `NotFound.dc.html` | В корпусе ничего не найдено |
| `Error.dc.html` | Модель недоступна |
| `Settings.dc.html` | Настройки, выбор языка |
| `canvas.json` | Раскладка холста, подписи, аннотации |

## Что в макете зафиксировано

- **Два уровня доказательств.** Основа — документы центра: цитаты с указанием страницы и раздела, сноски у утверждений ведут к ним. Подкрепление — документы ВОЗ ссылками, без цитат и без сносок. При расхождении приоритет за протоколом центра, и это сказано на экране.
- **Отказ вместо ответа по памяти.** Если в корпусе ничего не нашлось, система не отвечает и показывает, какие темы покрыты.
- **Признаки тревоги** только для распознанной темы и подписаны протоколом-источником, а не моделью.
- **Одна плотность.** Переключателя «Плотно / Свободно» нет; язык интерфейса живёт в настройках внизу боковой панели.

Требования, которые из этого следуют, записаны в изменении `openspec/changes/add-knowledge-layer`.

## Пересборка

Экраны — статические Design Components: правится `.dc.html`, затем канвас пересобирается и публикуется помощником Claude Design (скилл `/design`). Собранный `clinicompass-interface.html` в git не хранится — это ~2.5 МБ упакованного редактора, он воспроизводится из файлов выше.

Тексты фрагментов в макете иллюстративные: настоящие цитаты приходят из корпуса документов.
